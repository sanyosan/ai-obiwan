EPISODE Ⅶ
見せる者の覚醒

前回、我々は「集めろ」とだけ言われた。録音を、資料を、思いつきを。整理せず、分類せず、雑に放り込むだけでいいと。実際、箱は膨らんだ。

だが二ヶ月が過ぎ、多くの者が同じ場所で止まっていた。溜めた。読ませた。すごいと思った。そして、何も起きなかった。銀河には「詳しくなっただけの者」があふれていた。

その間、たった二ヶ月で二件の契約を決めた男がいた。使った道具は前回と同じ四つだけ。新しく買ったものは、ひとつも無い。

違いはひとつ。彼は溜めたものを、外に出して人に見せた。これは、その記録である……

結論を先に

今日やることは
「1人に見せる」だけです

うまく作らなくていい。完成していなくていい。動く画面を1枚、誰か1人に見せるところまでが今日の仕事で、決まるかどうかはその後に勝手に決まります。

CHAPTER I

詳しくなった者の墓場

まず、いちばん言いにくいことから言います。勉強した人ほど、動いていません。

逆張り

AIを勉強しても、
何も変わりません

勉強会に出た。本を読んだ。ChatGPTとClaudeとGeminiを比べた。プロンプトも溜めた。それで受注が増えた人を、僕は見たことがありません。

詳しくなることと、変わることは、別の話です。この二つを混ぜている間は、一生このままです。

まず僕の恥から

来ていた仕事を、
断りもせず4件落としました

◈ INCIDENT REPORT

顧問の紹介サービスに登録すると、企業からオファーが届きます。僕のところにも届いていました。4件。全部、返事をしないまま消えました。

断ったのではありません。気づかなかったんです。オファーの通知だけが別のメールアドレスに届いていて、そっちを見ていなかった。それだけ。

やる気の問題だと思いますか。違います。導線が2本に割れていただけです。

ここが今日の一番の学び

動けない人は、
たいてい根性ではなく
導線が壊れている

「やりたいけど時間がなくて」と言う人の話を分解すると、ほぼ全部ここに着きます。やる気を足すのではなく、漏れている線を1本、機械に持たせる。

人力で守るルールは必ず抜けます。抜けた自分を責めても、来月また抜けます。

CHAPTER II

効いたのは3つだけ

この二ヶ月で実際に前へ進んだ案件を全部並べて、共通するものだけを抜きました。

因数分解

3つを、ぐるぐる回す

その1見せるその場でデモを作って見せる。体感した相手には、競合が残らない
その2言い直す相手が言った課題を、自分の言葉で定義し直す。案件名は課題ではない
その3その場で答える持ち帰らない。精度より速度。持ち帰ると熱が冷める

この3つ以外は、正直どうでもよかった。順番も関係ありません。どれか1つでも刺さります。

逆に、効かなかったもの

資格も、実績表も、
プロフィールも

僕は資格を31個持っています。実績も並べられます。この3つの前では、1ミリも効いていません。

相手が動いたのは、いつも画面を見た瞬間か、自分の悩みを言い当てられた瞬間でした。紙を見た瞬間ではありません。

CHAPTER III

三つの記録

業種はバラバラです。製造、水産、物流。起きたことは同じでした。

DATA FILE 01 ／ 製造業

面談でデモを見せたら、
6日で決まった

◈ TRANSMISSION LOG

オンラインの初回面談。会社の説明はそこそこに、その場で画面を出しました。専務と部長が前のめりになった。

同席していた紹介会社の担当者から、翌日こう来ました。「デモを交えたご説明に感動されており、極めて前向きです」。面談から契約まで6日。

喋った内容ではありません。動いている画面を見たから決まりました。

DATA FILE 02 ／ 水産

見せられなかったので、
その日のうちに作って送った

◈ TRANSMISSION LOG

1時間の面談。準備が間に合わず、デモを見せられませんでした。終わってから作りました。全部ダミーデータの、予実が見えるだけの画面。その日のうちに送った。

返ってきた言葉。「あの短時間のヒアリングで、ここまで出来てしまうのは驚きです」。次の打合せに同席してほしいと頼まれました。

完成度ではありません。その日のうちだから効きました。1週間後なら、ただの資料です。

DATA FILE 03 ／ 物流

案件名を疑って、
返信1本で動いた

◈ TRANSMISSION LOG

届いた案件名は「データ分析業務の効率化」。そのまま受け取れば、分析ツールの話になります。受け取りませんでした。

返したのはこうです。「実際の課題は、足りないデータの中で仮説を立てるベテラン営業の頭の中が、言語化されていないことではありませんか」。返信1本で、担当者が動きました。

相手は課題を知っています。言葉にできていないだけです。言い直す人が、いなかっただけ。

3つの共通点

全部、溜めたものを
外に出した瞬間に動いた

前回の言葉で言えば、あふれたのは、外に出したときだけでした。箱の中で膨らんでいる間は、1件も動いていません。

集めるのは準備です。準備は、成果ではありません。

もう1つ、いま一番刺さっている型

「独学で進めてきたが、
社員に任せたら進まない」

いま相談が来る会社の入口は、ほぼ全部これです。社長が一人で没頭して、渡す段になって止まる。

この部屋にいる人ほど当てはまります。自分でできることと、人に渡せることは10倍違う。教える人を教えるのは、さらに3倍です。
