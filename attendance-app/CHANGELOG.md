# 更新履歴

未来創造家 勤怠アプリの変更点。新しいものが上。
`バージョン` は Apps Script 側の `APP_VERSION`（アプリの接続確認画面と `/exec` を直接開いたときに出る値）。

---

## 1.2.0 — 2026-09-07

**Slack通知**

- Slack に流したとき、通知の左に**色帯**が付くようになった
  緑=予定どおり / 黄=遅刻・早退 / 赤=未打刻・欠勤 / 青=予定・シフトの変更
- Slack宛ては見出し＋本文の形（`attachments`）で送るようにした。
  Google Chat と Discord はこれまでどおり
- Webhook がエラーを返したとき、これまでは黙って落ちていたのを
  **通知ログ**シートの「結果」欄にステータスコードごと残すようにした
- Apps Script のエディタから実行できる `testNotify()` を追加。
  設定を触ったあとにテスト通知を1通だけ飛ばして、経路が生きているか確かめられる
- README にSlackの受信Webhookの取り方を追記

**設定**

- `Webhook URL` の説明文を「Slackは色分けして届く」に更新

## 1.1.1 — 2026-09-06

**初期設定と再ログインのつまずきを減らす**

- 接続先URLの入力ミスを、その場で具体的に指摘するようにした
  - スプレッドシートのURLを貼った → 「それはスプレッドシートのURLです」
  - `/dev` で終わっている → 「それはテスト用のURLです」
  - 編集画面のURL、`/exec` で終わっていない、など
  （実際に「サーバーに接続できませんでした」で詰まったので入れた）
- **ログインの有効期間を設定で変えられるようにした**（設定シートの `ログイン有効日数`）。
  初期値を 30日 → **180日**に。同じiPhoneならPINの入れ直しが半年に1回で済む
- 期限切れトークンは認証のたびにその場で消すようにした
- 同じ端末で別の人がログインしたとき、端末名が前の人のまま残っていたのを直した
- KPIの数字とボタンの文字が折り返して崩れていたのを直した
- 画面の切り替え（`[hidden]`）が効かない場所があったのを直した

## 1.1.0 — 2026-09-05

**シフト機能**（月間予定表がメインの使い方になった）

- **シフト区分**（早番・日勤・遅番・在宅・外勤・半休・公休・有給）を登録できるようにした。
  時刻・休憩・勤務形態・色を区分ごとに決める
- **月間シフト表**（人 × 日のマス目）。区分を選んでマスを塗ると勤務予定に展開される
- 先月のシフトを流用（28日前から写すので曜日が揃う。手で直した日は上書きしない）
- 日ごとの出勤人数と、人ごとの勤務日数・休日数・実働時間の合計
- シフトを組む・変えると本人と管理者に通知
- GASへの導入をコピー1回で済むようにした（`paste-to-gas.gs`）

## 1.0.0 — 2026-09-05

**初回リリース**

- 社員マスター（5名）と、社員の追加・編集・退社処理
- 4桁PINでのログイン（Googleアカウント不要）＋アプリキーでの入口の締め
- 勤務予定（出勤予定・退勤予定）の登録。自分の分も、管理者なら他の人の分も
- 出勤・退勤の打刻。**出社（GPS）／リモート**を選べる
  - 出社なら位置情報と事業所からの距離、リモートなら位置は取らない
  - 端末IDと端末名を記録
- 予定と実績を突き合わせて **予定どおり／遅刻／早退／未打刻／欠勤** を判定
- 月次統計（勤務日数・実働・残業・遅刻回数・**リモート率**）
- 通知（メール＋Webhook）
  - 打刻したとき / 予定を変えたとき / 未出勤・未退勤アラート / 日締めの欠勤確定
- PWA（iPhone・Androidのホーム画面に追加して、アプリとして使える）
- PC のブラウザからも同じURLで使える
