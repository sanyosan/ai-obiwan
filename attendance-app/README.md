# 未来創造家 勤怠アプリ

出退勤の**予定**を登録し、**予定どおりに出勤・退勤できたか**を記録する自作アプリ。
スマホのホーム画面に置けば普通のアプリのように使える（PWA）。パソコンのブラウザからも同じものが使える。

```
  スマホ / PC                      Google Apps Script            スプレッドシート
 ┌──────────────┐   HTTPS   ┌──────────────────┐          ┌────────────────┐
 │  kintai/     │ ────────▶ │  attendance-app/gas │ ───────▶ │ 社員マスター     │
 │  （PWA）      │           │  ・打刻の判定        │          │ 勤務予定        │
 │  打刻/予定/統計 │ ◀──────── │  ・通知             │          │ 出退勤記録       │
 └──────────────┘           │  ・未打刻の見張り     │          │ 端末 / 通知ログ  │
                            └──────────────────┘          └────────────────┘
                                     │
                                     └─▶ メール・Slack等へ通知
```

- `kintai/` … スマホアプリの本体（HTML/CSS/JS だけ。どこに置いても動く）
- `attendance-app/gas/` … Google Apps Script のコード
- `attendance-app/test/` … サーバー側の動作確認（Node で動く）

---

## できること

**社員**

- 出勤予定・退勤予定をカレンダーで**まとめて登録**（「今月の平日を全部 9:00-18:00」がボタン1つ）
- 出勤／退勤の打刻。**「出社（GPS）／リモート／外出・直行直帰」を選べる**
- 出社を選ぶと位置情報が必須になり、緯度経度・誤差・住所・事業所からの距離を記録
- 打刻に使った端末（端末IDと端末名）も記録
- 自分の履歴と月次の統計を見る
- PINの変更

**管理者**

- 全員の履歴・統計を見る（メンバー別の一覧表つき）
- **社員の追加・編集・退社処理**（増えても減っても画面から対応できる）
- 他の人の予定を代理で登録
- 事業所の座標・遅刻猶予・通知のON/OFFなどの設定
- 登録された端末の一覧

**自動で届く通知**

| いつ | 内容 |
|---|---|
| 出勤・退勤の打刻をしたとき | 誰が何時に、どの勤務形態で、予定どおりか遅刻か、場所と端末 |
| 勤務予定を登録・変更・削除したとき | 対象日と時間 |
| 出勤予定を過ぎても打刻がないとき | 未出勤アラート（10分おきに見張る） |
| 退勤予定を大きく過ぎても打刻がないとき | 未退勤アラート |
| 打刻がないまま日をまたいだとき | その日の締めで欠勤にして通知 |

宛先は**本人のメール**と**管理者全員のメール**。Slack / Google Chat / Discord の Webhook にも同時に流せる。

## セットアップ

### A. スプレッドシートと Apps Script

1. <https://script.google.com/> で「新しいプロジェクト」を作る。名前は「未来創造家 勤怠」など。
2. 左の歯車（プロジェクトの設定）で **「appsscript.json マニフェスト ファイルをエディタで表示する」にチェック**。
3. `attendance-app/gas/` の中身をエディタに写す。
   - `appsscript.json` … 中身を貼り替える
   - `00_Config.gs` 〜 `09_Triggers.gs` … 「ファイル > +」でスクリプトを9個作り、それぞれ貼り付ける
   （`clasp` を使うなら `clasp push` で一気に入る）
4. 関数の一覧から **`setup`** を選んで実行。初回は権限の確認が出るので許可する。
5. 実行ログに次が出るので**控える**。
   - スプレッドシートのURL
   - **アプリキー**（24桁）
   - 各人の**初期PIN**
6. **デプロイ > 新しいデプロイ > 種類「ウェブアプリ」**
   - 説明: 任意
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   - デプロイして出てくる `https://script.google.com/macros/s/.../exec` を控える

> コードを直したら、**「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→ デプロイ**をしないと反映されない。URLは変わらない。

### B. スプレッドシート側の下ごしらえ

作られたスプレッドシートを開いて、

1. **社員マスター** … 氏名とメールアドレスを正しく直す。
   初期メンバーは音声メモからの**仮登録**なので、必ず確認する。
   メールアドレスが空の人には通知が届かない。
2. **設定** … `事業所緯度` `事業所経度` を入れる。
   Googleマップで事業所を右クリック → 出てくる数字が「緯度, 経度」。
   `事業所半径(m)` の内側なら「事業所内」と判定される。
3. 通知を Slack 等にも流すなら `Webhook URL` に受信Webhookを入れる。

### C. アプリ（PWA）を公開する

`kintai/` はただの静的ファイルなので、置き場所はどちらでもよい。

**Cloudflare Pages（おすすめ・国内で速い）**

1. Cloudflare にログイン → Workers & Pages → Create → Pages → Connect to Git
2. このリポジトリを選ぶ
3. ビルド設定
   - Framework preset: **None**
   - Build command: **空欄**
   - Build output directory: **`kintai`**
4. デプロイすると `https://<プロジェクト名>.pages.dev/` で開ける
5. 独自ドメインを当てるなら Custom domains から

**GitHub Pages（このリポジトリで既に使っている）**

Settings → Pages を有効にすれば `https://<ユーザー名>.github.io/ai-obiwan/kintai/` で開ける。
追加の設定はいらない（`_headers` は Cloudflare 用なので無視される）。

### D. スマホに入れる

1. 上のURLをスマホのブラウザで開く
2. 最初の画面に **APIのURL**（手順Aの `/exec`）と**アプリキー**を入れて「接続する」
   - URLの後ろに `?api=<URL>&key=<キー>` を付けたリンクを配れば自動で入る。
     このリンクをQRコードにして配ると全員分の初期設定が一瞬で終わる。
3. 名前を選んでPINでログイン
4. ホーム画面に追加する
   - **iPhone（Safari）**: 共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**: メニュー → 「アプリをインストール」
5. 位置情報の許可を聞かれたら**許可**する（出社の打刻に必要）

> iPhone は Safari で開いたときだけホーム画面に追加できる。Chrome アプリからだと出ない。

## 使い方

### 予定を登録する

「予定」タブ → カレンダーで日をタップして選ぶ（何日でも選べる）→ 時間と勤務形態を決めて「この内容で登録」。
「平日を全部選ぶ」を押せばその月の月〜金がまとめて選ばれる。
有給・公休を選ぶと時間欄は使わない。同じ日にもう一度登録すると上書きになる。

### 打刻する

「ホーム」タブ → 勤務形態を選ぶ → 大きな「出勤」／「退勤」を押すだけ。

- **出社** … 位置情報が取れないと打刻できない（不正防止）
- **リモート** … 位置情報なしでも打刻できる。取れたときは記録する
- **外出・直行直帰** … 位置情報が取れれば記録し、取れなくても打刻できる

打刻するとその場で判定が付く。

| 判定 | 意味 |
|---|---|
| 予定どおり | 遅刻も早退もなし |
| 遅刻 | 出勤予定 +猶予（初期値5分）より遅い |
| 早退 | 退勤予定より早い |
| 予定外出勤 | その日の予定が無いのに打刻した |
| 欠勤 | 予定があったのに打刻がないまま日をまたいだ |

実働は「退勤 − 出勤 − 休憩」。休憩は実働が6時間を超えたときに社員ごとの所定休憩（初期値60分）を引く。
残業は「実働 − 予定の実働」。数字はすべて設定シートで変えられる。

### 月次の統計

「統計」タブ。出勤日数・総実働・残業・遅刻・早退・欠勤に加えて、
**働き方の内訳とリモート率**が帯グラフで出る。
管理者が「全員」を選ぶとメンバー別の一覧表も出る（平均出勤時刻・平均退勤時刻つき）。

### 社員が増えたとき / 辞めたとき

「設定」タブ（管理者のみ）→ 社員 → 「＋ 追加」。
PINを空にすれば4桁が自動で発行され、追加後にトースト表示される。本人に伝える。
辞めた人は編集画面で**「在籍中」のチェックを外す**。行は消えないので過去の記録と集計はそのまま残る。

## データの中身

| シート | 役割 |
|---|---|
| 社員マスター | 社員ID・氏名・メール・PIN・権限・標準勤務時間・在籍 |
| 勤務予定 | 1人1日1行。出勤予定/退勤予定/勤務形態/区分 |
| 出退勤記録 | 1人1日1行。予定と実績、判定、遅刻・早退・実働・残業、位置情報、端末 |
| 端末 | 端末ID・端末名・プラットフォーム・最終利用日時 |
| 通知ログ | いつ誰に何を送ったか |
| 設定 | 事業所座標、猶予分、通知のON/OFF、Webhook URL |

スプレッドシートを直接直しても構わない（打刻の修正など）。
ただし**1行目の見出しは触らないこと**。列の名前でデータを読んでいる。

## セキュリティについて

- ログインは「社員を選ぶ + PIN」。PINを8回続けて間違えると10分ロックする
- APIは**アプリキー**が合わないと応答しない
- ログイン状態は30日で切れる
- PINは社員マスターに平文で入っている。**このスプレッドシートを社外に共有しないこと**
- 位置情報は打刻したその瞬間の1点だけを記録する。常時追跡はしない
- 端末IDはブラウザごとに発行する乱数で、個人を特定する情報は含まない

## 動作確認

サーバー側のロジックは Google に上げなくても Node で丸ごと動かせる。

```bash
node attendance-app/test/run.js
```

打刻・遅刻早退の計算・未打刻アラート・日次締め・統計・権限まわりなど92項目を通しで確認する。
`attendance-app/test/harness.js` が Apps Script のサービスをメモリ上で模擬している。

## よくあるつまずき

| 症状 | 原因と対処 |
|---|---|
| 「アプリキーが違います」 | 設定画面の入力ミス。GASの「プロジェクトの設定 > スクリプト プロパティ」の `APP_KEY` と見比べる |
| 「サーバーに接続できませんでした」 | デプロイの「アクセスできるユーザー」が**全員**になっているか確認 |
| コードを直したのに変わらない | 「デプロイを管理」で**新バージョン**にしていない |
| 位置情報が取れない | ブラウザとOSの両方で位置情報を許可する。iPhoneは 設定 > プライバシー > 位置情報サービス > Safari |
| 通知が来ない | 社員マスターのメールアドレスが空。設定シートの「メール通知」がOFF。GASの1日あたり送信上限（無料枠100通）も確認 |
| 打刻を間違えた | スプレッドシートの出退勤記録で時刻を直す。判定の再計算が要るときは管理者が予定を登録し直すと連動する |
| 画面が古いまま | ホーム画面のアプリを一度閉じて開き直す。ブラウザなら再読み込み |
