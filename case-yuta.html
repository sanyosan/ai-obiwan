営業ナレッジ
顕在化アプリ

配管設備営業の隠れたノウハウを、ライトに引き出す

のりさんが出したプロンプト

配管設備の営業を行っている人が居ます。 その人が持っているナレッジやノウハウ、営業の殺し文句など、隠れたナレッジをオープンにするアプリを作りたい ただし、そういったものに抵抗があるので、ライトに。ライトにしたい。 録音ボタンを作り、さらに、質問をします。 また、最初にカタログ等取扱商品のものを登録します ＡＩで質問を考えます。 営業ノウハウを顕在化するために必要な質問です 話し方や商品知識はもちろん、自分が培ってきたコツや、良い悪いなどを将来ＡＩでジャッジするためのもの 新人教育にもなるし、お客様お問い合わせチャットボットにもなる ナレッジを追加追加していくためのＡＩチャットボットです obsidianを育てるというやり方もあるし、どんどんＡＩで構造データを作るやり方もあると思う。それを考えて

最大の地雷

ジャッジを最初に見せたら終わり。「良い悪いを将来AIでジャッジする」は価値の中核だが、営業マンにその存在を最初に知らせたら喋らなくなる。抵抗がある人に「あなたのノウハウを採点します」は最悪の入り方。

だからv1の顔はこうする。「あなたの喋りが、そのまま新人の教科書になります」。評価ではなく、貢献。ジャッジ機能はずっと後、しかも本人が自分の成長を見るためだけに使い、他人と比較しない。

ライトにするための設計原則

  • 書かせない。文字入力は一切要求しない。録音ボタン1個だけ
  • 1回1問。「今日は1問だけです」と言い切る。10問並べたら開かない
  • 答えなくていい。パスボタンを大きく置く。義務にした瞬間に止まる
  • その日のうちに成果が返る。喋った内容が要約されて「これ、新人に渡せますよ」と戻ってくる。手応えが継続を作る

F1 ｜ 商品登録（土台）

カタログPDF、価格表、型番一覧を放り込む。これが先にあると、AIの質問が抽象論から具体に変わる。

  • 「営業のコツを教えてください」→ 誰も答えられない
  • 「このバルブ、競合品と比べて何を推してます？」→ 一瞬で喋れる

抵抗を下げる最大のコツが、実はここ。

F2 ｜ AIが質問を作る（心臓部）

カタログと過去の録音から、次の1問を生成する。質問の軸は4系統。

軸質問例何が取れるか
商品知識この型番、どんな現場に入れます？適用条件、選定基準
話し方・殺し文句値段が高いと言われたら何て返します？反論処理のスクリプト
判断のコツこの案件、受けない方がいいと思った瞬間は？暗黙知の中核
失敗過去に一番痛かった見積ミスは？教育価値が最も高い

4番目が一番のお宝だが、序盤で聞くと閉じる。信頼が溜まってから出す質問リストとして分けて管理する。

F3 ｜ 出口3つ

  • 新人教育：質問→ベテランの回答で並んだFAQ。そのまま研修教材
  • 顧客向けチャットボット：製品の選び方に答える
  • 将来のAIジャッジ：良い商談の型を学習
絶対にやること。社内向けと顧客向けを物理的に分離する。「あの客はこう言えば落ちる」が顧客向けボットから漏れたら会社が終わる。ナレッジ1件ごとに公開レベルのフラグを必須にし、デフォルトは社内限定。

Obsidian方式か、構造データ方式か

結論、両方使う。層で分けるのが正解。

原石層はObsidian

録音の文字起こしをそのままmarkdownで放り込む。理由は、人間が読めて、後から意味が変わっても壊れないから。営業マンの喋りは脱線が価値で、「そういえば昔こんな客が」の枝葉に本命の暗黙知が混ざっている。最初からDBのカラムに切ると、そこが捨てられる。

出口層は構造データ

チャットボットとAIジャッジは精度が要るので、markdownを読ませるだけでは足りない。Claudeに原石を読ませて、次のJSONに落とす。

{ 製品ID, 質問, 回答, 適用条件, 反論パターン, 公開レベル, 発言者, 日付 }

つまり原石はObsidianで人間が読む形、出口は構造データで機械が使う形。変換はClaudeがやる。三幕構成（集める→育てる→使う）と同じ形。

のりさん自身のVaultとは別Vaultにする。他人のナレッジで、しかも会社の資産。混ぜると権利関係が後で必ず揉める。

問題数と時間の設計

本人が自分のナレッジを出す場合、抵抗の壁がない。制約は心理ではなく、時間と網羅率になる。

  • 1問あたり2〜4分。90秒に縛ると浅い答えしか出ない。深掘りした方が価値が出る
  • 1セッション15〜25分／5〜7問。30分を超えると後半の答えが雑になる
  • 1日1セッション、週5日
項目数
主力商品（ABC分析のA・B）20品目
質問の軸4系統
総質問数80問
所要時間（1問3分）240分＝4時間
完了までの日数（1日20分）約12日

「無限に喋ってください」は始まらないが、「12日でひと通り終わります」なら着手できる。

密度は2周に分ける

  • 1周目：浅く広く（80問）。全商品・全軸を1問ずつ。ここで第一版の教科書が完成する
  • 2周目：深く狭く。1周目の回答をClaudeが読んで、薄い箇所・矛盾している箇所だけを狙って追い質問を生成。ここで暗黙知の核心が出る

1周目が終わった時点で成果物が完成するので、途中で止まっても教科書は残る。「終わらない不安」が消えるのが効く。

進捗を見せる

  • 商品×軸のマトリクスを塗り絵にする。80マスが埋まっていく
  • 埋まった率と、残り日数の目安を常に表示
  • 1周目完走で1回、明確に完成を宣言する

商品数と軸数を入れたら質問総数と日数が自動計算される形にしておく。配管で80問、印刷業なら工程が多くて150問、士業なら商品ではなく案件パターンで切る。
